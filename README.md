## mortgage.html — 房贷计算器

组合贷（商业贷款 + 公积金贷款）月供计算器，支持等额本息 / 等额本金两种还款方式。

### 功能

- **组合贷**：商业贷款与公积金贷款分开设利率、贷款额，支持只填其中一种
- **还款方式**：等额本息、等额本金
- **利率调整计划**：在还款期间的任意月份修改商贷 / 公积金利率
- **提前还款计划**：在任意月份追加偿还商贷 / 公积金本金（减少月供，期限不变）
- **还款明细表**：逐月展示期数、月供、本金、利息、余额，变更行高亮标记
- **导出 Excel**：将还款明细导出为 \*.xlsx 报表
- **参数持久化**：保存 / 加载参数为 JSON 文件，方便复用

### 用法

打开 `mortgage.html`，填写：
1. **总期数**（月）和 **首期年月**
2. **商贷 / 公积金** 的年利率和贷款金额
3. 点击 **重新计算**

点击明细表中的任意月份行，可为此月设置利率调整或提前还款。
